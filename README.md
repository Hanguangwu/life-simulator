# 模拟人生 - 网页游戏设计文档

注：本项目基于微信公众号文章设计实现，原作者没有给出代码。

# 原项目概述

一款基于浏览器的模拟人生网页游戏，玩家从出生到75岁，在每个关键人生节点做出选择，不同选择影响属性和人格走向，最终根据一生的抉择生成 MBTI 人格分析和人生总结。

- **技术栈**：纯 HTML + CSS + JavaScript（零依赖）

- **文件结构**：

- `index.html` — 页面结构与布局

- `css/style.css` — 全部样式

- `js/data.js` — 数据定义（出身、事件、MBTI、SBTI、成就）

- `js/game.js` — 游戏逻辑

---

## 游戏流程

```
选择性别 → 随机出身 → 人生事件（固定+随机） → 人生总结（MBTI / SBTI）
```

1. **选择性别**：男生/女生

2. **随机出身**：自动分配家庭背景，影响初始属性

3. **人生历程**：24个固定事件 + 随机事件，每个事件2~4个选择

4. **人生总结**：MBTI人格类型 / SBTI隐藏人格、维度分析、深度解读、属性终值、时间线回顾、人生评价

## MBTI 人格系统

### 维度映射

每个选择的 `mbti` 字段影响四个维度的积分：

| 维度   | 左极    | 右极    | 生活中的体现       |
| ---- | ----- | ----- | ------------ |
| 精力方向 | E（外向） | I（内向） | 社交活跃 vs 独处充电 |
| 认知方式 | S（感觉） | N（直觉） | 注重现实 vs 追求可能 |
| 判断方式 | T（思考） | F（情感） | 逻辑决策 vs 价值导向 |
| 生活方式 | J（计划） | P（灵活） | 有序规划 vs 随性而安 |

### 加权计算

MBTI 类型不仅由选择积分决定，还受属性加权影响：

- 高 **魅力** → 倾向 E（外向）

- 高 **智力** → 倾向 T（思考）、I（内向）

- 高 **幸福** → 倾向 F（情感）

- 高 **创造力** → 倾向 N（直觉）、I（内向）

- 高 **财富** → 倾向 T（思考）、J（计划）

最终类型 = 各维度加权积分较高者的组合。

## 结局评价系统

### 人生评级

综合6项属性平均值，分为6个等级：

| 评级  | 分数  | 描述   | 颜色         |
| --- | --- | ---- | ---------- |
| S   | ≥80 | 传奇人生 | 金色 #fdcb6e |
| A   | ≥70 | 精彩人生 | 绿色 #00b894 |
| B   | ≥60 | 充实人生 | 蓝色 #74b9ff |
| C   | ≥50 | 平凡人生 | 紫色 #a29bfe |
| D   | ≥40 | 坎坷人生 | 橙色 #e17055 |
| E   | <40 | 艰难人生 | 红色 #d63031 |

### 结局界面包含

1. **出身回顾**：显示出生时的家庭背景

2. **人格卡片**：MBTI 类型 / SBTI 隐藏人格、名称、emoji、格言、解读

3. **深度解读卡片**：你的样子（lifeStyle）+ 优势天赋 + 成长空间 + 专属建议

4. **维度分析**：4 个维度的加权倾向比例可视化

5. **最终属性**：6 项属性的终值展示

6. **人生时间线**：所有抉择的完整记录（随机事件用 ⚡ 标记）

7. **人生评价**：评级 + 人格专属人生感悟

8. **成就展示**：已解锁/未解锁成就网格

## 交互设计

### 键盘快捷键

- **A / 1**：选择第一个选项

- **B / 2**：选择第二个选项

- **C / 3**：选择第三个选项

- **D / 4**：选择第四个选项

- **Enter / 空格**：继续下一个事件

### 视觉特效

- 背景粒子动画（Canvas 实现）

- 事件卡片进入动画（fadeInUp）

- 属性条填充动画（barFill）

- MBTI 卡片旋转光效（conic-gradient + rotate）

- SBTI 隐藏人格卡片脉冲光晕（主题色边框 + box-shadow 动画）

- SBTI 徽章渐变发光（粉色→紫色 + glow 动画）

- 选择按钮悬停交互（边框高亮 + 位移）

### 响应式适配

- 适配移动端，小屏幕下自动调整布局

- 属性面板从双列变单列

- 性别选择卡片缩小

- 结局属性从三列变两列
